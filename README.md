# 肆意股份官网 (cn.segxm.com)

## 目录结构
- `*.html` — 静态页面
- `assets/` — JS/CSS 构建产物
- `css/` — 预编译 Tailwind CSS
- `images/` — 图片资源
- `nginx/` — Nginx 配置备份
- `public/` — Express 服务端 public 目录

## 服务器
- ECS: 121.196.174.145
- Web root: /var/www/cn.segxm.com/web/
- CMS DB: /opt/segxm-cms/cms.db

## 部署
直接将文件同步到服务器 `/var/www/cn.segxm.com/web/` 目录即可。
